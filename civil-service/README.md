# 计算机专业公务员岗位雷达

面向计算机科学与技术及相近专业，自动检索近三年国考、省考和政府部门招录资料，归纳主要岗位方向、地区与待遇证据。程序优先保留政府官网结果，跨运行去重，生成 Markdown/JSON 报告；复用本仓库 Gmail 发件凭据，但使用独立收件地址，每天最多成功发送一封卡片式 HTML 日报。

## 主要观察维度

- 岗位：信息化/电子政务、网络安全/网信、公安技术/网络警察、数据管理/统计分析、专业监管/技术监管、综合管理/行政执法。
- 地区：省会不是硬条件，省直、市直、普通城区、县、县级市全部纳入，每个省级行政区都会额外执行一条区县专项查询，区县岗位不会因为行政层级较低而降分。湖北（含武汉）与川渝（四川、成都、重庆）增加 30 分区域权重并在报告和邮件中单独置顶。基础匹配分仍只衡量岗位本身，最终工作地点以职位表为准。
- 待遇：只摘录官方页面明确出现的金额；未披露时标记“公告未公开金额”。依据《公务员法》，工资由基本工资、津贴、补贴和奖金构成，并依法享受住房、医疗等补贴补助和社会保险。
- 年份：默认 2026、2025、2024，可在 workflow 手动运行时修改。

## 全国覆盖与地区过滤

- 每个年份都会逐项扫描中国大陆 31 个省级行政区，并为每个省区市追加区县/县级市专项查询，同时单独执行国考查询；报告会列出每个省区市是否已扫描、有效资料数及本轮未命中地区。
- 全国发现按配置并发执行，默认并发数为 6；报告同时记录查询数、搜索返回数、基准来源数与抓取失败数，便于判断是“已扫描但无结果”还是抓取异常。
- 普通县、城区、县级市不会被排除；只有明确标注为艰苦边远、边境县/边境乡镇、边境一线、高原艰苦、南疆四地州、三州三区，或明确海拔达到配置阈值的结果才会被排除，并在报告中留下过滤原因。
- 不按省区名称粗暴排除：新疆、西藏、内蒙古、广西等仍会正常扫描；只有页面明确命中上述条件时才过滤。

## 自动运行

GitHub Actions 每天北京时间运行五次，全部避开整点高负载窗口：

- 07:17（UTC 前一日 23:17，主发送窗口）
- 09:43（UTC 01:43）
- 13:29（UTC 05:29）
- 17:47（UTC 09:47）
- 21:13（UTC 13:13，当日最后补发）

分钟刻意避开整点，因为 GitHub 官方说明定时任务在每小时开始时负载较高，更容易延迟。定时调度仍可能有少量延迟，属于平台正常行为。

五次扫描都会刷新 GitHub 报告。当天第一次运行会尝试发邮件；单次运行内 SMTP 最多重试 3 次，如果仍失败则让 Actions 明确失败，且不写入成功标记。后续四个错峰时段会继续补发，直到当天有一次被 SMTP 确认成功。成功时间写入 `state/seen.json`，成功后的其余批次只更新报告、不重复发信。`GMAIL_USER`、`GMAIL_APP_PASSWORD`、`CIVIL_SERVICE_MAIL_TO` 任一缺失都会让工作流失败，不会静默跳过邮件。

## 输出

- `output/latest.md`：适合直接阅读的最新报告。
- `output/latest.json`：结构化明细，便于二次分析。
- `output/history/YYYY-MM-DD.md`：每天一份归档，当天四次运行会更新同一文件，避免仓库膨胀。
- `state/seen.json`：只保存链接、标题和首次/最后发现时间，用于去重。

邮件和报告会把“具体职位”放在公告线索之前，逐项展示地区、招录单位、职位名称、人数、匹配等级/分数、资格提示和官方职位表链接。往年职位会明确标注为面向 2028 届的历史模板预测，不会伪装成当前可报名岗位；边境、艰苦边远和高海拔规则同样适用于这些具体职位。

## 手动运行

```bash
node civil-service/scan.mjs --dry-run
node civil-service/scan.mjs --no-mail --years 2026,2025,2024 --limit 80
node civil-service/scan.mjs --force-mail # 仅迁移或测试时使用，会忽略当天已成功发送记录
node civil-service/test.mjs
```

邮件复用当前仓库的 `GMAIL_USER`、`GMAIL_APP_PASSWORD` 发件凭据，但收件人只读取独立 Secret `CIVIL_SERVICE_MAIL_TO`。原实习雷达继续读取 `MAIL_TO`，两套程序的收件地址互不影响。工作流会在 `CIVIL_SERVICE_MAIL_TO` 缺失时明确失败，避免误发到发件邮箱或原收件地址。

手动运行工作流时可将 `force_mail` 设为 `true`，用于地址迁移后的单次测试。正常定时任务仍严格遵守“每天最多一次发送成功”。

## 数据边界

搜索摘要不能替代职位表。自动归类只用于发现线索，报考资格、专业代码、学历学位、应届身份、政治面貌、基层经历、工作地点、落户地点和待遇必须以当年官方职位表及招录机关答复为准。程序不会把事业单位或国企招聘当作公务员岗位，也不会用论坛传闻估算收入。
